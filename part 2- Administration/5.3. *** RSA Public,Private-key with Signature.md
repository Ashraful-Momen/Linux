# 🔐 RSA Key Concept (Basic Idea)

RSA-তে ২টা key থাকে:

```text id="rsa1"
Public Key  = (e, n)
Private Key = (d, n)
```

* `n` = বড় prime number থেকে বানানো modulus (shared)
* `e` = public exponent (সবাই জানে)
* `d` = private exponent (secret)

---

# 🧠 Simple Concept

```text id="rsa2"
Public Key  → Lock খুলতে পারে (Verify)
Private Key → Lock লাগাতে পারে (Sign)
```

---

# Step 1: Key Generation

ধরো system বানালো:

```text id="rsa3"
p = 61
q = 53
n = p × q = 3233
```

ASCII:

```text id="rsa4"
   p = 61
   q = 53
     \   /
      \ /
       v
      n = 3233
```

তারপর:

```text id="rsa5"
Public Key  = (e = 17, n = 3233)
Private Key = (d = 413, n = 3233)
```


# 📨 Digital Signature Concept (Real Meaning)

Signature মানে:

> "আমি Private Key দিয়ে কিছু encrypt করেছি যাতে সবাই verify করতে পারে"

---

# Step 2: Message

ধরো message:

```text id="rsa7"
M = 123
```

---

# Step 3: Signing (Private Key ব্যবহার)

Signature তৈরি:

```text id="rsa8"
S = M^d mod n
```

```text id="rsa9"
S = 123^413 mod 3233
```

এটাই signature।

ASCII:

```text id="rsa10"
Message (M)
   123
    |
    v
+------------------+
| Private Key (d)  |
+------------------+
    |
    v
Signature (S)
   855
```

ASCII:

---

# Step 4: Verification (Public Key দিয়ে)

Server check করে:

```text id="rsa13"
M' = S^e mod n
```

```text id="rsa14"
M' = 855^17 mod 3233
```

Result:

```text id="rsa15"
M' = 123
```

---

# Step 5: Match Check

```text id="rsa16"
Original Message = 123
Recomputed       = 123
```

ASCII:

```text id="rsa17"
        Signature Verification

        855^17 mod 3233
                 |
                 v
              Result = 123

        Compare:
        123 == 123  ✔
```

# 🔐 Real Meaning (Very Important)

## Public Key:

* সবাই জানে
* শুধু verify করার জন্য

## Private Key:

* শুধু owner জানে
* signature বানানোর জন্য
