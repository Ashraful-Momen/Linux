আপনার রিকোয়ারমেন্ট অনুযায়ী, ডাটাবেজে আপলোড করা একটি বইয়ের উপর ভিত্তি করে ইউজার যখন কোনো প্রশ্ন করবে, তখন Laravel এবং MCP (Model Context Protocol) কীভাবে কাজ করবে তা নিচে সহজভাবে বুঝিয়ে দেওয়া হলো এবং একটি মিনি ওয়ার্কিং প্রোটোটাইপ কোড তৈরি করে দেওয়া হলো।

## ১. 📘 আপনার সিস্টেমে MCP-এর উপাদানগুলোর ভূমিকা

* 
* Prompt (প্রম্পট): এটি হলো আপনার তৈরি করা নির্দেশনার টেমপ্লেট। যেমন: "তুমি একজন বুক অ্যাসিস্ট্যান্ট। নিচে দেওয়া বইয়ের কনটেক্সট থেকে ইউজারের প্রশ্নের উত্তর দাও।" এটি এআই-কে তার কাজের পরিধি বুঝিয়ে দেয়।
* Resource (রিসোর্স): ডাটাবেজে থাকা আপনার বইয়ের টেক্সট বা চ্যাপ্টারগুলো হলো রিসোর্স। এটি Read-Only। এআই এটি পড়ে ব্যাকগ্রাউন্ড নলেজ বা কনটেক্সট পাবে, কিন্তু বইয়ের ভেতরের লেখা পরিবর্তন করতে পারবে না।
* Tool (টুল): ডাটাবেজ থেকে বইয়ের সঠিক চ্যাপ্টার খুঁজে বের করার জন্য যে ফাংশন বা কুয়েরি (Book::where(...)) রান করতে হবে, সেটিই হলো টুল। এআই যখন দেখবে ইউজারের প্রশ্নের উত্তর দিতে বইয়ের ডেটা লাগবে, তখন সে নিজে থেকে এই টুলটি কল করবে।

## ২. 🚀 সম্পূর্ণ সিস্টেমের আর্কিটেকচার ও কোড (Laravel)
বাস্তব ক্ষেত্রে MCP সার্ভার চালাতে Anthropic-এর নির্দিষ্ট প্রোটোকল মেইনটেইন করতে হয়, তবে লারাভেলে এটিকে ইমিটেট (Imitate) করার জন্য আমরা একটি সহজ এপিআই আর্কিটেকচার তৈরি করব যেখানে এআই (যেমন OpenAI বা Claude) এপিআই-এর সাথে লারাভেলের Route, Controller এবং DB ইন্টিগ্রেট হবে।
আমরা একটি .env, Migration, Route, এবং Controller এর কমপ্লিট সেটআপ নিচে ফাইল আকারে তৈরি করে দিয়েছি।
এখানে আপনার সম্পূর্ণ কোড সম্বলিত ফাইলটি দেওয়া হলো: mcp_laravel_system.md.

# 1. Environment Configuration (.env)OPENAI_API_KEY=your_openai_api_key_here
OPENAI_MODEL=gpt-4o
# 2. Database Migration (create_books_table.php)Schema::create('books', function (Blueprint $table) {
    $table->id();
    $table->string('title');
    $table->longText('content'); // বইয়ের মূল টেক্সট বা রিসোর্স
    $table->timestamps();
});
# 3. Routes (routes/api.php)use App\Http\Controllers\McpBookController;

Route::post('/ask-book', [McpBookController::class, 'ask']);
# 4. Controller (app/Http/Controllers/McpBookController.php)namespace App\Http\Controllers;

use Illuminate\Http\Request;
use App\Models\Book;
use Illuminate\Support\Facades\Http;

class McpBookController extends Controller
{
    public function ask(Request $request)
    {
        $request->validate([
            'book_id' => 'required|exists:books,id',
            'user_question' => 'required|string',
        ]);

        $bookId = $request->book_id;
        $question = $request->user_question;

        // === ১. RESOURCE: DB থেকে বইয়ের কনটেক্সট রিড করা ===
        $book = Book::find($bookId);
        $resourceContext = "Book Title: " . $book->title . "\nContent: " . $book->content;

        // === ২. PROMPT: এআই-এর জন্য রেডিমেড টেমপ্লেট বা গাইডলাইন ===
        $systemPrompt = "You are an expert Book AI Assistant. Your task is to answer the user's question based strictly on the provided book content resource. If the answer cannot be found in the resource, say 'I cannot find this in the book.'";

        // === ৩. TOOL Execution & AI API Call ===
        // এখানে আমরা এআই-এর কাছে প্রম্পট এবং রিসোর্স কনটেক্সট একসাথে পাঠাচ্ছি
        $response = Http::withHeaders([
            'Authorization' => 'Bearer ' . env('OPENAI_API_KEY'),
            'Content-Type' => 'application/json',
        ])->post('https://openai.com', [
            'model' => env('OPENAI_MODEL', 'gpt-4o'),
            'messages' => [
                ['role' => 'system', 'content' => $systemPrompt],
                ['role' => 'system', 'content' => "RESOURCE CONTEXT:\n" . $resourceContext],
                ['role' => 'user', 'content' => $question],
            ],
            'temperature' => 0.3,
        ]);

        if ($response->successful()) {
            $aiAnswer = $response->json()['choices'][0]['message']['content'];
            return response()->json([
                'success' => true,
                'book_title' => $book->title,
                'question' => $question,
                'answer' => $aiAnswer
            ]);
        }

        return response()->json([
            'success' => false,
            'message' => 'Failed to connect with AI service.'
        ], 500);
    }
}

## ৩. 🛠️ এটি যেভাবে কাজ করবে (Workflow)
১. রিকোয়েস্ট পাঠান: ইউজার Postman বা আপনার ফ্রন্টএন্ড থেকে /api/ask-book রাউটে book_id এবং user_question লিখে POST রিকোয়েস্ট পাঠাবে।
২. রিসোর্স ফেচিং: কন্ট্রোলার মেথডটি রান হবে এবং Book::find() কুয়েরি (যা এখানে একটি Tool হিসেবে পর্দার আড়ালে কাজ করছে) চালিয়ে ডাটাবেজ থেকে বইয়ের ডেটা (Resource) তুলে আনবে।
৩. এআই প্রসেসিং: এরপর লারাভেল আপনার দেওয়া নির্দেশনাবলী (Prompt) এবং বইয়ের ভেতরের টেক্সট (Resource) একসাথে প্যাকেজ করে এআই এপিআই-তে পাঠিয়ে দেবে।
৪. আউটপুট: এআই সম্পূর্ণ বই না জেনেই শুধুমাত্র আপনার পাঠানো স্পেসিফিক রিসোর্স থেকে উত্তরটি নিখুঁতভাবে তৈরি করে লারাভেলে ফেরত পাঠাবে, যা ইউজার তার স্ক্রিনে দেখতে পাবে।
আপনি কি এই সিস্টেমে বড় বইয়ের ক্ষেত্রে Semantic Search বা Vector Embeddings (যাতে পুরো বই একসাথে এপিআই-তে না পাঠিয়ে শুধু রিলেভেন্ট অংশ পাঠানো যায়) যুক্ত করার নিয়ম জানতে চান?
