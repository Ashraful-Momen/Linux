1. TERMINAL SHORTCUTS (Essential Keyboard Combinations)
--------------------------------------------------------------------------------
Ctrl + A             | Cursor to Beginning   | Moves cursor to the start of the line
Ctrl + E             | Cursor to End         | Moves cursor to the end of the line
Ctrl + K             | Kill (Cut) Line       | Cuts text from cursor position to end of line
Ctrl + Y             | Yank (Paste) Line     | Pastes the text that was cut using Ctrl+K
Ctrl + L             | Clear Screen          | Clears the terminal display window
Ctrl + R             | Search History        | Search previously used commands interactively

3. LINUX COMMAND SYNTAX (Case-Sensitive)
--------------------------------------------------------------------------------
* Linux commands are strictly Case-Sensitive (e.g., 'ls' is not 'LS').
* Structure: command  [option]  [argument]
* Example:   ls       -arl      /Desktop

[Detailed Explanation of the Example Command]:
Command: ls -arl /Desktop
  ├── ls       --> (Command) Lists directory contents.
  ├── -arl     --> (Combined Options/Flags):
  │     ├── -a --> All (Shows all files, including hidden files starting with a dot '.')
  │     ├── -r --> Reverse (Reverses the order of the sort)
  │     └── -l --> Long listing format (Shows file permissions, size, owner, and date)
  └── /Desktop --> (Argument) The target directory you want to inspect.


4. BASH HISTORY MANAGEMENT
--------------------------------------------------------------------------------
* User History File Location: ~/.bash_history
* Maps out previously run terminal tasks per user. Retains standard command logs.

cat .bash_history            | View All History | Displays the full history log at once
less .bash_history           | Efficient View   | Scrollable view [Use Shift+PageUp/PageDown]
head .bash_history           | View First 10    | Shows the first 10 commands ever saved
head -15 .bash_history       | View First 15    | Shows exactly the first 15 lines of history
tail .bash_history           | View Last 10     | Shows the last 10 commands executed
tail -20 .bash_history       | View Last 20     | Shows exactly the last 20 lines of history
tail -f .bash_history        | Live Follow Mode | Monitors history updates in real-time
sudo cat ~/.bash_history     | Admin Logs Scan  | Runs as root to view privileged history data


5. FILE & DIRECTORY OPERATIONS (CRUD)
--------------------------------------------------------------------------------
[Make File & Folder]:
mkdir [folder]               | Create Directory | Creates a brand new folder
mkdir -p [p_folder/c_folder] | Parent/Recursive | Creates nested subfolders without errors
touch [file_name]            | Create File      | Creates an empty file or updates timestamp
touch [folder/file_name]     | Target File Gen  | Creates an empty file inside a specific folder

[Show Directory Content (ls Options)]:
ls -l                        | Long List View   | Displays permissions, size, owner, and date
ls -a                        | Show Hidden Files| Shows all files, including hidden dot (.) files
ls -r                        | Reverse Order    | Reverses alphabetical sorting order
ls -t                        | Sort by Time     | Shows newest files/folders first
ls -tr                       | Reverse Time Sort| Shows oldest files/folders first

[Copying Files & Folders (cp)]:
cp [source] [destination]    | Base Copy Format | Standard layout for copying files
cp /tmp/testfile.txt /Documents/Shuvo/          | Copies file directly into target folder
cp /tmp/testfile /Documents/Shuvo/newName.txt   | Copies and changes the file's name
cp -r /tmp/dir1/ Documents/  | Recursive Copy   | Copies entire folder along with its content
cp -r /tmp/dir1/ Documents/different_name/      | Copies and renames the folder at target
cp -i /tmp/test/file Documents/ | Interactive   | Asks Confirmation (Y/N) before overwriting
cp /tmp/move_item ~/Documents/ | Home Path Copy | Copies item into Current User's Home Docs

[Moving & Renaming Files (mv)]:
mv [source] [destination]    | Base Move Format | Standard layout for moving/renaming items
mv -i /dir/file Documents/   | Interactive Move | Asks Confirmation (Y/N) before overwriting
mv /root/files .             | Move to Current  | Moves target content into current folder (.)
mv /tmp/move_item ~/Documents/ | Home Path Move | Moves item into Current User's Home Docs

[Removing Files & Folders (rm)]:
rm /tmp/testFile             | Delete File      | Deletes a standard file permanently
rmdir /tmp/testDir           | Delete Empty Dir | Removes an empty folder (or use rm -r)
rm -r /tmp/testDir           | Recursive Delete | Deletes a folder and all its contents
rm -ri /tmp/testDir          | Interactive Del  | Prompts for confirmation before every deletion
rm -rf /tmp/testDir          | Force Delete     | Deletes everything forcefully without prompt
