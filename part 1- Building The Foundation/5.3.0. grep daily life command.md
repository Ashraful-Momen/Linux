নিচে **`grep` Daily Use Cheat Sheet** দিলাম। এগুলো Linux Admin, DevOps, Backend Developer, Security—সব জায়গায় প্রায় প্রতিদিন লাগে।

---

# grep Cheat Sheet

## 1. সাধারণ Search

```bash
grep "error" app.log
```

---

## 2. Case Ignore (`-i`)

```bash
grep -i "error" app.log
```

ম্যাচ করবে:

```
error
Error
ERROR
```

---

## 3. Line Number (`-n`)

```bash
grep -n "error" app.log
```

Output

```
35:error occurred
87:error found
```

---

## 4. Count Match (`-c`)

```bash
grep -c "error" app.log
```

Output

```
15
```

---

## 5. Invert Match (`-v`)

যা match করবে না তা দেখাবে।

```bash
grep -v "nologin" /etc/passwd
```

---

## 6. Recursive Search (`-r`)

Folder এর ভিতরে search

```bash
grep -r "DB_PASSWORD" .
```

---

## 7. Recursive + Line Number

```bash
grep -rn "TODO" .
```

---

## 8. Show Filename (`-H`)

```bash
grep -H "localhost" *.conf
```

---

## 9. Only Filename (`-l`)

```bash
grep -l "DB_HOST" *.env
```

Output

```
.env
.env.production
```

---

## 10. Filename Without Match (`-L`)

```bash
grep -L "DB_HOST" *.env
```

---

## 11. Exact Word (`-w`)

```bash
grep -w "root" /etc/passwd
```

---

## 12. Regex (`-E`)

```bash
grep -E "jpg|png|jpeg" file.txt
```

---

## 13. Multiple Pattern

```bash
grep -E "error|warning|fatal" app.log
```

---

## 14. Start With (`^`)

```bash
grep "^root" /etc/passwd
```

---

## 15. End With (`$`)

```bash
grep "/bin/bash$" /etc/passwd
```

---

## 16. Empty Line

```bash
grep "^$" file.txt
```

---

## 17. Non Empty Line

```bash
grep -v "^$" file.txt
```

---

## 18. Context Before (`-B`)

```bash
grep -B 3 "ERROR" app.log
```

৩ লাইন আগে দেখাবে।

---

## 19. Context After (`-A`)

```bash
grep -A 5 "ERROR" app.log
```

---

## 20. Context Both (`-C`)

```bash
grep -C 2 "ERROR" app.log
```

---

## 21. Pipe এর সাথে

```bash
cat app.log | grep ERROR
```

অথবা আরও ভালো:

```bash
grep ERROR app.log
```

---

## 22. Process Search

```bash
ps aux | grep nginx
```

---

## 23. Port Search

```bash
ss -tulpn | grep 80
```

---

## 24. Docker

```bash
docker ps | grep mysql
```

---

## 25. PM2

```bash
pm2 list | grep online
```

---

## 26. Systemd

```bash
systemctl list-units | grep nginx
```

---

## 27. Environment Variable

```bash
env | grep JAVA
```

---

## 28. User Search

```bash
grep ashraful /etc/passwd
```

---

## 29. Bash User

```bash
grep "/bin/bash$" /etc/passwd
```

---

## 30. Exclude Binary File

```bash
grep -I "password" *
```

---

# Daily Useful Combinations

```bash
grep -rn "TODO" .
grep -rin "password" .
grep -rw "config" .
grep -v "^#" file.conf
grep -v "^$" file.txt
grep "^root" /etc/passwd
grep "/bin/bash$" /etc/passwd
grep -c "ERROR" app.log
grep -A 5 "ERROR" app.log
grep -B 3 "ERROR" app.log
grep -C 2 "ERROR" app.log
ps aux | grep nginx
ss -tulpn | grep 443
docker ps | grep mysql
env | grep PATH
journalctl | grep ERROR
```

# সবচেয়ে বেশি ব্যবহৃত Option (মনে রাখুন)

| Option | কাজ                    |
| ------ | ---------------------- |
| `-i`   | Case ignore            |
| `-n`   | Line number            |
| `-v`   | Not match              |
| `-r`   | Recursive              |
| `-w`   | Exact word             |
| `-c`   | Count                  |
| `-l`   | Filename only          |
| `-L`   | Filename without match |
| `-A`   | After lines            |
| `-B`   | Before lines           |
| `-C`   | Context                |
| `-E`   | Extended regex         |
| `-H`   | Show filename          |

👉 **এই ১২টি option (`-i`, `-n`, `-v`, `-r`, `-w`, `-c`, `-l`, `-L`, `-A`, `-B`, `-C`, `-E`) আয়ত্ত করলে `grep`-এর প্রায় ৯০% দৈনন্দিন কাজ করতে পারবেন।**
