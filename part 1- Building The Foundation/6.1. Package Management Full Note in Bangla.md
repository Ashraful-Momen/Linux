# Linux Package Management (APT & DPKG) - বাংলা নোট

Linux (বিশেষ করে Debian, Ubuntu, Kali Linux) এ সফটওয়্যার ইনস্টল, আপডেট, রিমুভ করার জন্য **APT (Advanced Package Tool)** এবং **DPKG (Debian Package Manager)** ব্যবহার করা হয়।

```txt
Internet Repository
        │
        ▼
       APT
        │
        ▼
      DPKG
        │
        ▼
   Installed Package
```

* **APT** = Online package management করে।
* **DPKG** = `.deb` package install/remove করে (Offline-ও কাজ করে)।

---

# ১. Package Search

## Package খোঁজা

```bash
apt search package_name
```

অথবা

```bash
apt-cache search package_name
```

### Example

```bash
apt search nginx
```

Output:

```txt
nginx/stable
nginx-common/stable
nginx-core/stable
```

এখানে nginx সম্পর্কিত সব package দেখাবে।


অথবা

# ৪. Package Remove

```bash

```

অথবা

```bash
apt-get remove package_name
```

### Example

```bash

```

এতে:

✅ Software remove হবে

❌ Configuration file থাকবে

---

# ৫. Package Purge

```bash
apt purge package_name
```

অথবা

```bash
apt-get purge package_name
```

### Example

```bash
sudo apt purge nginx
```

এতে:

✅ Software remove হবে

✅ Configuration file remove হবে

---

## Difference

```txt
remove
 ├── software delete
 └── config file keep

purge
 ├── software delete
 └── config file delete
```

---

# ৬. Auto Remove

অনেক package install করার সময় dependency install হয়।

যদি মূল package remove করা হয়, dependency গুলো থেকে যেতে পারে।

সেগুলো remove করতে:

```bash
sudo apt autoremove
```

### Example

```bash
sudo apt autoremove
```

এতে unused dependency remove হবে।

# Wildcards

Wildcards ব্যবহার করে একসাথে অনেক file match করা যায়।

---

## `*` → Zero বা অনেক Character

```bash
ls *.txt
```

Match করবে:

```txt
note.txt
linux.txt
hello.txt
```

---

## `?` → Exactly One Character

```bash
ls file?.txt
```

Match করবে:

```txt
file1.txt
file2.txt
fileA.txt
```

Match করবে না:

```txt
file10.txt
```

কারণ এখানে দুইটা character আছে।

---

## `[]` → নির্দিষ্ট Character Match

```bash
ls file[123].txt
```

Match:

```txt
file1.txt
file2.txt
file3.txt
```

---

## `\` → Escape Character

```bash
touch my\ file.txt
```

ফাইল তৈরি হবে:

```txt
my file.txt
```

# Which

বর্তমানে command execute হলে কোন path থেকে run হচ্ছে তা দেখায়।

```bash
which command_name
```

### Example

```bash
which php
```

Output:

```txt
/usr/local/bin/php
```

---

### Internally কী হয়?

```txt
php
 │
 ▼
PATH Variable Search
 │
 ▼
/usr/local/bin/php
 │
 ▼
Execute
```

---

### Symbolic Link Example

```bash
ln -s /opt/lampp/xampp /usr/local/bin/xamp
```

এখন:

```bash
which xamp
```

Output:

```txt
/usr/local/bin/xamp
```

মানে `xamp` command চালালে আসলে `/opt/lampp/xampp` run হবে।

# Whereis

Command, Binary, Source, Manual কোথায় আছে দেখায়।

```bash
whereis package_name
```

### Example

```bash
whereis php
```

Output:

```txt
php:
/usr/bin/php
/usr/share/man/man1/php.1.gz
```

---

## Difference Between locate, which, whereis

| Command | কাজ                                        |
| ------- | ------------------------------------------ |
| locate  | পুরো filesystem database থেকে file খুঁজে   |
| which   | PATH এর মধ্যে executable command খুঁজে     |
| whereis | binary, source, man page এর location দেখায় |

# Interview Question

### APT এবং DPKG এর মধ্যে পার্থক্য কী?

| APT                           | DPKG                          |
| ----------------------------- | ----------------------------- |
| High Level Package Manager    | Low Level Package Manager     |
| Dependency Handle করে         | Dependency Handle করে না      |
| Online Repository ব্যবহার করে | Local `.deb` file ব্যবহার করে |
| apt install nginx             | dpkg -i nginx.deb             |

# মনে রাখার Shortcut

```txt
apt update
    ↓
apt install nginx
    ↓
apt upgrade
    ↓
apt remove nginx
    ↓
apt purge nginx
    ↓
apt autoremove
```

**Rule:**

```txt
update  = package list refresh
upgrade = package update
install = package install
remove  = package remove
purge   = package + config remove
autoremove = unused dependency remove
dpkg    = offline package management
which   = command কোথা থেকে run হচ্ছে
whereis = binary + source + man page location
locate  = file search
```
