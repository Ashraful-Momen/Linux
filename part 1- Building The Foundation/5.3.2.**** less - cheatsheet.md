অবশ্যই। তুমি যখন:

```bash
less /etc/apt/sources.list
```

দিয়ে file দেখছো, তখন **keyboard shortcut** দিয়ে up/down, page movement, search—সব করতে পারবে।

### 📜 Up / Down

| Shortcut   | কাজ            |
| ---------- | -------------- |
| `↑`        | এক line উপরে   |
| `↓`        | এক line নিচে   |
| `k`        | এক line উপরে   |
| `j`        | এক line নিচে   |
| `Ctrl + U` | half page উপরে |
| `Ctrl + D` | half page নিচে |
| `Ctrl + B` | full page উপরে |
| `Ctrl + F` | full page নিচে |

### 📄 Page-এর শুরু/শেষ

```text
g       → file-এর একদম শুরু
G       → file-এর একদম শেষ
```

### 🔍 Word/Text Search

ধরো `deb` খুঁজবে:

```text
/deb
```

তারপর:

```text
Enter
```

পরের match:

```text
n
```

আগের match:

```text
N
```

উদাহরণ:

```text
/ubuntu
Enter
```

তারপর `n` চাপলে পরের `ubuntu` match-এ যাবে।

### ❌ Search বন্ধ/clear

```text
Esc
```

### 🚪 বের হতে

```text
q
```

---

### 🧠 সবচেয়ে বেশি ব্যবহার করবে এইগুলো

```text
↑ ↓       → line up/down
Ctrl+D    → half page down
Ctrl+U    → half page up
Ctrl+F    → full page down
Ctrl+B    → full page up

g         → beginning
G         → end

/text     → search
n         → next match
N         → previous match

q         → quit
```

**একটা গুরুত্বপূর্ণ ব্যাপার:** `less`-এর মধ্যে `/` চাপলে search mode আসে। যেমন:

```text
/PermitRootLogin
```

তারপর `Enter` → match খুঁজবে → `n` → পরের match → `N` → আগের match।
